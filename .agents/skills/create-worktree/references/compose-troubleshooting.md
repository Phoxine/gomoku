# Troubleshoot a worktree's Compose environment

Work from the affected checkout; use `git rev-parse --show-toplevel` to confirm it and `bash scripts/compose.sh` to select its project. Do not print environment files, resolved Compose configuration, or credentials. Logs can contain sensitive data; inspect and report only what is necessary.

- **Docker or service startup:** Check daemon availability and permissions. Use `bash scripts/compose.sh ps -a` and, as needed, `bash scripts/compose.sh logs --tail=100 app db` to identify the failing service. Resolve socket access through the normal permission process. Inspect health and database authentication errors without exposing secrets. Preserve existing database credentials and volumes; do not regenerate them to bypass an error.
- **Recovering a stack:** Before starting or recreating services, identify the original Compose configuration and respect the scope of the request. The base stack uses `bash scripts/compose.sh up --build -d`; the local web stack uses `bash scripts/compose.sh -f compose.web.yaml up --build -d`. Starting the base configuration over a web stack can replace the server command and remove its published port. A read-only diagnosis does not authorize restarting services.
- **Port conflict:** The base stack publishes no host port; the web override uses `APP_PORT`. Identify the process or container holding the port and choose a distinct port using the local-server setup in [README](../../../../README.md#play-locally). An exported `APP_PORT` can override the worktree setting. Do not stop unrelated services.
- **Isolation or missing environment:** Follow the [worktree isolation reference](multi-session-worktrees.md) and the initializer's diagnostics. Do not copy or symlink another worktree's environment, reuse its project name, or delete a database volume to resolve a mismatch. Preserve the existing project and credentials; explicitly plan any needed database migration.
- **Stop hook skipped:** A `Skipping final validation` message is not a pass. Check the affected worktree's initialization and `bash scripts/compose.sh ps --status running --services`; resolve project or daemon errors, then start the correct stack if authorized. Run `bash .codex/hooks/stop-validation.sh` and confirm formatting, lint, and tests complete rather than skip.

Report the observed cause, checks and result, and any remaining limitation. Never use `down -v` without explicit authorization.
